# Security Policy

## Reporting a Vulnerability

If you discover a security issue on **zeppreader.com** or in this repository — for example, an XSS vulnerability, exposed secrets, a dependency with a known CVE, or an issue with the contact form's data handling — **please do not open a public GitHub issue.**

Instead:

1. Open a private report via **GitHub's [Security Advisories](https://github.com/NVCDevelopmentTeam/Zepp-OS-ScreenReader/security/advisories/new)** for this repository, or
2. Email **[contact@zeppreader.com](mailto:contact@zeppreader.com)** with details, or
3. Contact a maintainer directly through their GitHub profile

Please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce, if possible
- The affected page/URL and browser, if relevant

## Scope

This policy covers the **website** (this repository). For vulnerabilities in the **watch app itself**, see the [SECURITY.md in the main app repo](https://github.com/NVCDevelopmentTeam/Zepp-OS-ScreenReader/blob/main/SECURITY.md).

## What to Expect

- We'll acknowledge your report as soon as possible.
- Response time may vary given the project's limited maintainer resources, but security reports are prioritized over feature work.
- We'll keep you informed as the issue is investigated and, where applicable, credit you in release notes (unless you prefer to remain anonymous).

## Supported Versions

As a continuously deployed website, only the version currently live on `main` / production is supported with security fixes.

Thank you for helping keep this site and its visitors safe.
